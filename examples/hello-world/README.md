# Hello World example

A counter demonstrating an application window, React state, and a button signal. It uses the Adwaita and GTK bindings generated by default.

Complete the [workspace setup](../../website/contributing/development.md), then run from the repository root:

```bash
pnpm --filter hello-world dev
```

To create a standalone app, follow [Getting Started](https://gtkx.dev/v2/guide/getting-started).
