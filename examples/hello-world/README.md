# hello-world

The smallest complete GTKX app: a native GNOME window built with Adwaita, React state, a label, and a button signal. Adwaita and GTK bindings are generated by default.

```bash
pnpm --filter hello-world dev
```

Run from the repository root after `pnpm install` and `pnpm build`. Continue with [Getting Started](https://gtkx.dev/guide/getting-started).
