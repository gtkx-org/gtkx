# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets).

We have a quick list of common questions to get you started engaging with this project in
[our documentation](https://github.com/changesets/changesets/blob/main/docs/common-questions.md).

## Using changesets in this repo

```bash
# Describe a change after editing source. Choose the affected packages and
# whether the change is a patch, minor, or major bump. A markdown file gets
# written into .changeset/ for you to commit alongside your code change.
pnpm changeset

# Aggregate all pending changesets into a versioning commit. Done by CI,
# not usually by humans.
pnpm version-packages

# Build and publish all packages whose versions changed. Done by CI.
pnpm release
```

Public packages are versioned in **lockstep** — every release moves all of
`@gtkx/cli`, `@gtkx/css`, `@gtkx/ffi`, `@gtkx/gir`, `@gtkx/mcp`,
`@gtkx/native`, `@gtkx/react`, `@gtkx/testing`, and `@gtkx/vitest` to the
same version. Platform packages (`@gtkx/native-linux-*`) are managed by the
native build pipeline and ignored here.
