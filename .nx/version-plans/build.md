`gtkx build` keeps line breaks in the minified bundle so a load error prints one line, names the source of an unresolvable import or a native addon, and produces the same worker chunk names in any checkout. It rejects `--out` inside the deploy directory and leaves linked workspace packages out of the third-party notices. GSettings schema summaries are available in bundles and AppImages, and identical schema copies are installed once.
