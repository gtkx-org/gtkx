The MCP server adds `gtkx_press_keys`, which presses keys and shortcuts such as `{Enter}` or `{Control>}s{/Control}`, and `gtkx_pointer`, which presses mouse buttons such as `[MouseRight]` to open context menus. `gtkx_search_api` and `gtkx_get_api_docs` find and return single class members, also by JSX element name, as in `GtkSourceView.showLineNumbers`. Widget summaries now report the accessible name as `name`; read `type` for the widget's type.
