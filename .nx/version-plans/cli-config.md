Configuration fields show their documentation in editors, including inside `$development` and `$production`, and each section has an exported type such as `DeployOptions`. Directory layers in `extends` load in every command, a missing `applicationId` reports "is required", and a relative `module` in `elements.config` resolves from the project root. Codegen finds Debian's multiarch GIR directory, libraries that fail to load report the linker's reason, and commands announce binding regeneration before it starts.
