`quit()` ends applications that hold themselves and runs `onShutdown`, apps with `HANDLES_OPEN` render when launched with files, and a second launch hands over to the running instance quietly. The program name comes from the application ID before the entry runs, so `--help` and X11 window classes no longer say `node`. Rendering an application window outside an application element explains what is missing.
