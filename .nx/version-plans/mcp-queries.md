`gtkx_query_widgets` and `gtkx_get_widget_tree` search every open window, match accessible names and labels with `by: "name"`, and report widgets inside disabled containers as insensitive. Summaries include a text view's text and boxed values such as colors in string form. Tools reject arguments they do not declare, `gtkx_press_keys` says when a modifier stays held, and `gtkx_click` reports when nothing handled a click.
