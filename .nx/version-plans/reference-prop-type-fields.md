Element reference pages now list the fields of the object types that configured props take, such as `GtkLevelBar`'s `offsets`, `GtkScale`'s `marks`, `GtkConstraintLayout`'s `vfl` and `GMenu`'s `items`, and name enum types in those props by their public names (`Gtk.TextDirection`) rather than internal ones (`_TextDirection`).
