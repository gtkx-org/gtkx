The Storybook explorer's navigator now keeps story groups whose titles share a path together, such as `Recipes/Card` and `Recipes/Grid` or `Pantry/Spices/Cumin` and `Pantry/Spices/Pepper`, with the first story file under each path deciding where it appears, as in Storybook's sidebar. Groups used to follow the order of their files, so a catalogue organised by title path was scattered across the list.
