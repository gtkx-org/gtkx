GTKX is a framework for building native GTK4 and libadwaita desktop applications with React, TypeScript, and JSX. It binds the GNOME stack (GTK4, libadwaita, GLib/GObject) the same way [GJS](https://gitlab.gnome.org/GNOME/gjs), [node-gtk](https://github.com/romgrk/node-gtk), and PyGObject do, with typed bindings generated from GObject-Introspection (GIR) across the whole widget surface, and gives you the React programming model on top: components, hooks, and Fast Refresh over real GObject instances.

## Demo

![GTKX demo](https://raw.githubusercontent.com/gtkx-org/gtkx/main/demo.gif)

The window above is rendered by the app below. The JSX element types are real GTK widgets, and standard React (hooks, events) drives them:

```tsx
import * as Gtk from "@gtkx/gi/gtk";
import { GtkApplication, GtkApplicationWindow, GtkBox, GtkButton, GtkLabel } from "@gtkx/jsx/gtk";
import { createRoot, quit } from "@gtkx/react";
import { useState } from "react";

const Counter = () => {
  const [count, setCount] = useState(0);

  return (
    <GtkApplicationWindow
      title="Hello GTKX"
      defaultWidth={400}
      defaultHeight={300}
      onCloseRequest={quit}
    >
      <GtkBox
        orientation={Gtk.Orientation.VERTICAL}
        spacing={20}
        marginTop={40}
        marginBottom={40}
        marginStart={40}
        marginEnd={40}
        valign={Gtk.Align.CENTER}
        halign={Gtk.Align.CENTER}
      >
        <GtkLabel label="Welcome to GTKX!" cssClasses={["title-1"]} />
        <GtkLabel label={`Count: ${count}`} cssClasses={["title-2"]} />
        <GtkButton
          label="Increment"
          onClicked={() => setCount((c) => c + 1)}
          cssClasses={["suggested-action", "pill"]}
        />
      </GtkBox>
    </GtkApplicationWindow>
  );
};

const App = () => (
  <GtkApplication>
    <Counter />
  </GtkApplication>
);

createRoot().render(<App />);
```

This is the [`hello-world`](https://github.com/gtkx-org/gtkx/tree/main/examples/hello-world) example, verbatim. `@gtkx/gi` and `@gtkx/jsx` are per-project bindings generated by the CLI (under `node_modules/.gtkx`), not packages you install from npm.

## How it works

Under the hood, a custom react-reconciler maps your JSX tree to live GObject instances, while a Rust napi addon owns the single GLib main-loop thread and performs every call into GTK. A build-time generator turns GObject-Introspection (GIR) XML into the typed bindings, JSX element types, and reconciler metadata the runtime consumes, so the bindings cover the entire GTK4 and libadwaita API rather than a hand-picked subset.

## Why GTKX

- **Real React.** Components, hooks, and Fast Refresh, the same model you already use on the web.
- **The full GTK4 + libadwaita surface.** Every widget, fully typed, generated from GObject-Introspection instead of hand-curated.
- **Native, no webview.** Real GObject widgets with no DOM in the path, and single-file production builds.
- **Modern tooling.** A Vite-based CLI for scaffolding, a hot-reloading dev server, single-file production bundling, and GTK-asset integration.
- **Styling and animation.** `@gtkx/css` brings Emotion-style CSS-in-JS to GTK CSS classes, and `@gtkx/animate` provides libadwaita-driven animation components.
- **Testing and AI.** `@gtkx/testing` with `@gtkx/vitest` provides a headless Testing Library-style harness, and `@gtkx/mcp` exposes live widgets to AI agents over the Model Context Protocol.

## Requirements

GTKX runs on Linux. You need:

- Linux with GTK4, libadwaita, and GLib development libraries
- Node.js 24 or later

The Rust `@gtkx/native` addon ships prebuilt for common platforms; other targets build it from source and need a Rust toolchain.

## Quick start

Scaffold and run a new app with the official `create-gtkx` initializer:

```sh
npm create gtkx@latest
```

The same command works with other package managers: `pnpm create gtkx`, `yarn create gtkx`, or `bun create gtkx`. Then:

```sh
cd my-app
npm run dev
```

Every scaffolded app exposes the standard `dev`, `build`, and `start` scripts, which wrap the CLI (`gtkx dev`, `gtkx build`, `node dist/bundle.js`).
