# Native GTKX stories

The [Storybook guide](../website/v2/guide/storybook.md) covers setup, native controls and actions, preview ownership, and integration tests.

The [example project](../examples/storybook) includes component, dialog, and window stories. From a repository checkout, run `pnpm nx dev storybook-example` to open it or `pnpm nx test storybook-example` to run its native integration tests.
