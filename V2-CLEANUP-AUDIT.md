# V2 Cleanup Audit

Decision ledger for the cleanup work after PR #595 on `refactor/v2-cleanup-followup`. The implementation diff, excluding this report, is 3,250 insertions and 34,544 deletions: **31,294 net LOC removed across 252 files**. LOC includes tracked source, tests, guides, configuration, and lockfile lines. Exact figures are measured diffs; `~` figures are net estimates after a necessary adapter; `gross` figures are the size of code that is not currently replaceable.

## Native testing decisions not taken

| Candidate | Decision and reason |
| --- | --- |
| Remove every memory tool | Not done. A small ASan canary remains for out-of-bounds access, use-after-free, invalid frees, and corruption in Rust/libffi/NAPI/libuv allocations that a semantic refcount ledger cannot observe. It fails fast and runs only memory, symbol, and worker-boundary scenarios. |
| Enable LeakSanitizer for the Node suite | Not done. Node, GLib, and process-global caches make whole-process reachability a noisy ownership oracle, while not every loaded native library is instrumented. The generated fixture instead counts creation, refs, copies, dispose/finalize/weak notifications, callback destroys, live allocations, and duplicate releases deterministically. |
| Vendor `GIMarshallingTests` or `Regress` | Not done. Vendoring their C sources, GIR annotations, and build/version compatibility would restore a large fixture surface without the deterministic lifecycle counters required here. The compact local fixture supplies object, boxed, and callback counters, while the system Graphene, Pango, and GdkPixbuf GIRs supply production-scale real-library coverage. |
| Retain the generated callable sweep, factories, or blacklist | Not done. The inventory now scans every configured and transitive namespace without invoking arbitrary APIs. Manual representatives cover each of the 36 descriptor helpers, so process exit, global mutation, display, filesystem, network, indefinite callback, and explicit-destruction APIs need neither execution nor an exclusion list. |
| Cover every descriptor option and operation context | Not done. The audit found 214 option-sensitive profiles and 416 nested combinations across arguments, returns, fields, properties, callbacks, signals, and vfuncs. Treating each as a separate subject would recreate the oversized suite this cleanup removes. The gate intentionally follows the requested type-level definition and ignores arity; focused lifecycle and retained E2E cases cover ownership, callbacks, fields, signals, and vfuncs where the distinction changes observable behavior. |
| Read refcounts or finalizer state from every production native type | Not done. GObject refcounts are observed only through the declared C layout in the fixture, and production GObjects use weak/finalize notifications. Boxed, fundamental, and container internals have no uniform public refcount ABI. Instrumented deep-copy, ref-counted-boxed, callback, and object types provide deterministic create/copy/ref/free/finalize and duplicate-release counters instead. |
| Remove the remaining 11 native E2E files | Not done. A generic GIR factory cannot prove wrapper identity, registered-class behavior, class-closure overrides, nested callbacks, lent-pointer invalidation, regex match-info lifetime, or GDK surface teardown. Their 185 former cases were reduced to 31 happy/edge/error integration cases. |
| Read production GObject refcounts by byte offset | Not done. The former hard-coded offset oracle was deleted. Refcounts are inspected only by the C fixture through the declared `GObject` layout; production cases use wrapper weak references and observable lifecycle outcomes instead. |
| Replace Miri and Rust line coverage one-for-one | Not done. Miri cannot execute the real Node/GLib/libffi boundary, and a Rust line percentage rewarded mock execution rather than consumer behavior. This accepts less standalone pointer-provenance and line-count data in exchange for testing the actual loader, Node environments, generated bindings, GC, and native finalizers. |
