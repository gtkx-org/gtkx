# @gtkx/testing

Test GTKX applications with native widgets.

Render components, query widgets by accessible role or name, drive pointer and keyboard input, and capture screenshots. Importing the package registers widget matchers and automatic cleanup. Use the GTKX Vitest plugin to provide the headless display.

In an existing GTKX 2.0 beta app:

```sh
npm install -D @gtkx/testing@beta
```

[Guide](https://gtkx.dev/v2/guide/testing) · [API reference](https://gtkx.dev/v2/reference/@gtkx/testing/) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
