# @gtkx/react

The React renderer for GTKX.

Create a root with `createRoot`, render an `AdwApplication`, and compose widgets from `@gtkx/jsx`. This package provides application and widget hooks, portals, and the renderer lifecycle. The CLI generates the JSX elements for your configured native libraries.

In an existing GTKX 2.0 beta app:

```sh
npm install @gtkx/react@beta
```

[Guide](https://gtkx.dev/v2/guide/getting-started) · [API reference](https://gtkx.dev/v2/reference/@gtkx/react/) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
