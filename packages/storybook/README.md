# @gtkx/storybook

Explore GTKX components as native stories.

Write Component Story Format stories, open them with `gtkx storybook`, and change props through Controls. Actions record interactions, and portable stories can also serve as native integration-test fixtures.

In an existing GTKX app:

```sh
npm install -D @gtkx/storybook@beta
```

[Guide](https://gtkx.dev/v2/guide/storybook) · [API reference](https://gtkx.dev/v2/reference/@gtkx/storybook/) · [GTKX](https://gtkx.dev)

**GTKX 2.0 beta.** Requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started).
