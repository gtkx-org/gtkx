# @gtkx/storybook

Native component stories for GTKX.

Write Component Story Format stories, open them with `gtkx storybook`, and change props through Controls. Actions record interactions. Use `composeStories` to render the same stories in native integration tests.

In an existing GTKX app:

```sh
npm install -D @gtkx/storybook@beta
```

[Guide](https://gtkx.dev/v2/guide/storybook) · [API reference](https://gtkx.dev/v2/reference/@gtkx/storybook/) · [GTKX](https://gtkx.dev)

GTKX requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started).
