# @gtkx/navigation

React Navigation navigators for GTKX.

Build stack, tab, drawer, and split-view navigation with native Adwaita containers. The guide covers typed routes, nested navigators, Back behavior, and adaptive master/detail layouts.

In an existing GTKX 2.0 beta app:

```sh
npm install @gtkx/navigation@beta
```

[Guide](https://gtkx.dev/v2/guide/navigation) · [API reference](https://gtkx.dev/v2/reference/@gtkx/navigation/) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
