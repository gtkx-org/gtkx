# @gtkx/navigation

React Navigation navigators for GTKX.

Build stack, tab, drawer, and split-view navigation with native Adwaita containers. Define typed routes, nest navigators, and adapt sidebar and content layouts to the available space.

In an existing GTKX app:

```sh
npm install @gtkx/navigation@beta
```

[Guide](https://gtkx.dev/v2/guide/navigation) · [API reference](https://gtkx.dev/v2/reference/@gtkx/navigation/) · [GTKX](https://gtkx.dev)

GTKX requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started).
