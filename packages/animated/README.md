# @gtkx/animated

Spring animations for GTKX widgets.

Animate widget properties with `animated`, `useSpring`, and `useTransition`. The integration drives React Spring from the GTK frame clock and respects the desktop animation settings.

In an existing GTKX 2.0 beta app:

```sh
npm install @gtkx/animated@beta
```

[Guide](https://gtkx.dev/v2/guide/animations) · [API reference](https://gtkx.dev/v2/reference/@gtkx/animated/) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
