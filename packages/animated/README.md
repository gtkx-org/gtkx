# @gtkx/animated

Spring animations for GTKX widgets.

Animate widget properties with `animated`, `useSpring`, and `useTransition`. React Spring uses the GTK frame clock and skips animations when the desktop disables them. Use `useReducedMotion` to adapt effects to motion preferences.

In an existing GTKX app:

```sh
npm install @gtkx/animated@beta
```

[Guide](https://gtkx.dev/v2/guide/animations) · [API reference](https://gtkx.dev/v2/reference/@gtkx/animated/) · [GTKX](https://gtkx.dev)

**GTKX 2.0 beta.** Requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started).
