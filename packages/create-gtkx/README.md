# create-gtkx

Create native GTK and Adwaita apps with React and GTKX.

Scaffold an app with TypeScript or JavaScript, an Adwaita window, and optional Vitest support.

Start on Linux with Node.js and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started#what-you-need) installed:

```sh
npm create gtkx@beta my-app
cd my-app
npm run dev
```

For the application ID, language, tests, package manager and other options, see [Scaffold Options](https://gtkx.dev/v2/guide/scaffold-options).
