# create-gtkx

Create a GTKX application.

Scaffold a Linux app with React, TypeScript or JavaScript, an Adwaita window, and optional testing support.

```sh
npm create gtkx@beta my-app
cd my-app
npm run dev
```

Install the [native prerequisites](https://gtkx.dev/v2/guide/getting-started) first. For language, test, package-manager, and overwrite options, see [Scaffold Options](https://gtkx.dev/v2/guide/scaffold-options).

[Guide](https://gtkx.dev/v2/guide/getting-started) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
