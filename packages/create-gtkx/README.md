# create-gtkx

Create native Linux applications with React and GTKX.

Scaffold an app with TypeScript or JavaScript, an Adwaita window, and optional Vitest support.

Start on Linux with Node.js and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started) installed:

```sh
npm create gtkx@beta my-app
cd my-app
npm run dev
```

For language, test, package-manager, and overwrite options, see [Scaffold Options](https://gtkx.dev/v2/guide/scaffold-options).
