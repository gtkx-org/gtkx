# @gtkx/utils

Shared Node.js utilities used by GTKX packages.

Provides logging, executable discovery, process management, and string, path and collection helpers. GTKX packages install it as a dependency; apps don't import it. To start an app, run `npm create gtkx@beta`.

[Guide](https://gtkx.dev/v2/guide/getting-started) · [GTKX](https://gtkx.dev)

GTKX requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started#what-you-need).
