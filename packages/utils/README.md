# @gtkx/utils

Shared utilities for the GTKX toolchain.

Used by GTKX packages for executable discovery, logging, and other shared operations. It is installed as a dependency of the toolchain; application setup starts with `create-gtkx`.

[Guide](https://gtkx.dev/v2/guide/getting-started) · [GTKX](https://gtkx.dev)

**GTKX 2.0 beta.** Requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started).
