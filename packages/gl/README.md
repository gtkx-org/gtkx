# @gtkx/gl

OpenGL 4.6 core bindings for GTKX applications.

Render with `GtkGLArea` using bindings generated from the Khronos registry. Calls require a current GL context, and available features depend on the device and driver.

In an existing GTKX app:

```sh
npm install @gtkx/gl@beta
```

[Guide](https://gtkx.dev/v2/guide/opengl) · [API reference](https://gtkx.dev/v2/reference/@gtkx/gl/) · [GTKX](https://gtkx.dev)

GTKX requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started).
