# @gtkx/gl

OpenGL bindings and drawing helpers for GTKX.

Render with `GtkGLArea` using generated OpenGL 4.6 bindings. Calls require a current GL context, and available features depend on the device and driver. The guide covers context setup, redraws, and resource cleanup.

In an existing GTKX 2.0 beta app:

```sh
npm install @gtkx/gl@beta
```

[Guide](https://gtkx.dev/v2/guide/opengl) · [API reference](https://gtkx.dev/v2/reference/@gtkx/gl/) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
