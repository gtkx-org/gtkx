# @gtkx/forms

React Hook Form controls for GTKX.

Connect Adwaita entry, password, spin, switch, and combo rows to React Hook Form. The controls integrate validation and field state; the package also re-exports React Hook Form hooks and types.

In an existing GTKX 2.0 beta app:

```sh
npm install @gtkx/forms@beta
```

[Guide](https://gtkx.dev/v2/guide/forms) · [API reference](https://gtkx.dev/v2/reference/@gtkx/forms/) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
