# @gtkx/forms

React Hook Form controls for GTK and Adwaita apps.

Connect Adwaita entry, password, spin, switch, and combo rows to React Hook Form. An invalid field gets the `error` style class and shows its message as a tooltip. The package also re-exports React Hook Form hooks and types.

In an existing GTKX app:

```sh
npm install @gtkx/forms@beta
```

[Guide](https://gtkx.dev/v2/guide/forms) · [API reference](https://gtkx.dev/v2/reference/@gtkx/forms/) · [GTKX](https://gtkx.dev)

GTKX requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started#what-you-need).
