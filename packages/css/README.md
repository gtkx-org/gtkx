# @gtkx/css

CSS-in-JS for GTKX widgets.

Use `css` to create a class name, `cx` to combine classes, and `injectGlobal` for global rules. Apply classes through the `cssClasses` prop. Styles use GTK CSS properties and selectors; browser layout rules do not apply.

In an existing GTKX 2.0 beta app:

```sh
npm install @gtkx/css@beta
```

[Guide](https://gtkx.dev/v2/guide/css) · [API reference](https://gtkx.dev/v2/reference/@gtkx/css/) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
