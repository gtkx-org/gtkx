# @gtkx/cairo

Cairo drawing for GTK apps built with GTKX.

Draw paths, text, and images in a `GtkDrawingArea` callback or on an offscreen surface. For drawing techniques, see the [Cairo manual](https://www.cairographics.org/manual/).

Apps created with `npm create gtkx` already depend on this package. Otherwise:

```sh
npm install @gtkx/cairo@beta
```

[Guide](https://gtkx.dev/v2/guide/cairo) · [API reference](https://gtkx.dev/v2/reference/@gtkx/cairo/) · [GTKX](https://gtkx.dev)

GTKX requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started#what-you-need).
