# @gtkx/cairo

Cairo drawing for GTKX applications.

Use drawing contexts, surfaces, patterns, and fonts from a GTK drawing callback. The guide starts with a `GtkDrawingArea` and explains how to resize and redraw its contents.

In an existing GTKX 2.0 beta app:

```sh
npm install @gtkx/cairo@beta
```

[Guide](https://gtkx.dev/v2/guide/cairo) · [API reference](https://gtkx.dev/v2/reference/@gtkx/cairo/) · [GTKX](https://gtkx.dev)

GTKX runs on Linux with Node.js and system native libraries. See [Getting Started](https://gtkx.dev/v2/guide/getting-started) for supported versions and installation. This README describes the 2.0 beta.
