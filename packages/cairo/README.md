# @gtkx/cairo

Cairo drawing for GTKX applications.

Draw paths, text, and images in a `GtkDrawingArea` callback or on an offscreen surface. The guide covers contexts, patterns, resizing, and redraws.

In an existing GTKX app:

```sh
npm install @gtkx/cairo@beta
```

[Guide](https://gtkx.dev/v2/guide/cairo) · [API reference](https://gtkx.dev/v2/reference/@gtkx/cairo/) · [GTKX](https://gtkx.dev)

GTKX requires Linux, Node.js, and the [native prerequisites](https://gtkx.dev/v2/guide/getting-started).
