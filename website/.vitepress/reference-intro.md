# API Reference

Use this reference for GTKX package APIs: rendering, testing, navigation, components, and configuration. It is generated from the package sources.

For native widget props, signals, and methods, use your project's generated element reference. `gtkx codegen` writes `.gtkx/reference/index.md` for coding agents; `gtkx docs` produces browsable Markdown under `docs/reference`. These pages match the GIR libraries installed for that project.

Import native classes, enums, and functions from `@gtkx/gi/<namespace>`, and JSX elements from `@gtkx/jsx/<namespace>`. Those modules are generated locally; their APIs are separate from the GTKX package reference here.
