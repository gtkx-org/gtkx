# Development Principles

This page will collect the software development principles GTKX adheres to. They will guide implementation decisions, code review, and the systematic review of the codebase for GTKX 2.0.

::: info Principles are being prepared
The full list will be added here once it has been defined. The architecture and tooling pages describe the current implementation; they do not establish the forthcoming development principles.
:::

For now, use [Development Setup](/contributing/development) for the contribution workflow, [Architecture](/contributing/architecture) to understand the implementation, and [Testing](/contributing/testing) to run the existing checks.
